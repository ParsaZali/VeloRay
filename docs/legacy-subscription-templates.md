# 3x-ui style subscription HTML compatibility

VeloRay 1.0 can render the supplied `modernX.html`, `sub (2).html` and `sub.html`
without editing those original files. Settings → Subscription → Custom HTML file
uses the same confined template directory and **Validate template** action.

The installer seeds these examples on install/upgrade and preserves local edits:

| Supplied file | Server template path |
|---|---|
| `modernX.html` | `/etc/veloray/templates/legacy/modernX.html` |
| `sub (2).html` | `/etc/veloray/templates/legacy/sub-dashboard.html` |
| `sub.html` | `/etc/veloray/templates/legacy/sub-fish.html` |

Select one path, validate it, and save settings. No traffic-core restart or token
rotation is needed. Existing native VeloRay template variables remain supported.
The supplied HTML is stored as an example; compatibility changes happen in memory
when the file is loaded. The operator's on-disk file is not rewritten.

## Variables and formats

| Legacy variable | Meaning |
|---|---|
| `sId` | Public account/client label, not another access credential |
| `enabled` | Effective account activity boolean |
| `isOnline` | Boolean from fresh supported telemetry; null when unknown |
| `lastOnline` | Last traffic timestamp in Unix milliseconds; zero if unknown |
| `expire` / `expireUnix` | Expiry in Unix milliseconds / seconds; zero for unlimited |
| `downloadByte`, `uploadByte` | Actual directional traffic bytes |
| `totalByte`, `usedByte` | Quota limit and authoritative charged usage bytes |
| `rawUsedByte` | Total actual usage, including legacy traffic without a direction |
| `download`, `upload`, `used`, `total`, `remained` | Human-readable sizes; unlimited is explicit |
| `subUrl` | Current account subscription URL |
| `subJsonUrl`, `subClashUrl` | Xray client JSON and Clash feed URLs |
| `subTitle`, `subSupportUrl`, `announce` | Existing panel site/support/announcement settings |
| `links`, `emails` | Aligned portable URIs and account display names (the legacy field name is `emails`) |
| `datepicker` | `gregorian`; the browser template can select Jalali presentation |

Go template built-ins such as `range`, `if`, `len`, `lt` and `index` work normally.
Literal `"{{"` / `'{{'` inside legacy JavaScript strings are escaped before Go
parsing while retaining their JavaScript value, so placeholder checks can run.
Missing or malformed unsupported variables still fail validation and trigger the
normal buffered fallback at request time.

`?format=info` returns only account usage/expiry/online metadata, never raw
configuration, credentials, device identifiers or other accounts. Automatic info
polls do not fill subscription request history. Fresh telemetry is aggregated
across eligible account connections; unknown data is not guessed as offline.
Inactive/expired subscriptions retain the existing access policy.

`?format=json` retains VeloRay's existing metadata contract. The legacy
`subJsonUrl` points to `?format=xray`, and the supplied fish template's JSON link
is adapted accordingly. This avoids breaking existing API consumers.

The adapter fixes the supplied templates' seconds/milliseconds mismatch and uses
`usedByte` for their quota calculations. Upload/download figures remain actual
traffic, so customer multipliers and historical unclassified traffic do not get
misrepresented as directional usage. Their URI source is read as text, preserving
`&` query parameters rather than copying HTML entities into connection links.

## Scripts, icons and QR

Known QRious, QRCode and QR-server usages are replaced with a same-origin QR
adapter. PNG data is generated by VeloRay; bearer subscription URLs and connection
credentials are not sent to a third-party QR service. QR requests accept only the
current subscription/feed URLs or its own exported connection URIs. Connection
QRs retain HWID admission checks. The global Show QR setting still applies.

The current adapter provides the QR constructor/value and holder/makeCode/clear
operations used by these files; it is not a complete replacement for every API
of every QR library. QR output uses medium error correction and a black/white PNG.
The unused Chart.js include in the supplied dashboard is removed; that template
uses its own canvas chart. Templates that actually require Chart.js need a local
compatible library asset rather than relying on that unused include.

Phosphor 2.1.1 and Font Awesome Free 6.5.2 styles/fonts are local verified assets,
with their licenses included. Persian text uses the existing local Vazirmatn
variable font; the Roboto family name uses the bundled Inter fallback. Supported
examples need no external script/font/icon/QR requests. Public presentation assets
also work on the independent subscription service without exposing the admin SPA.

CSP remains limited to self-hosted scripts and exact rendered inline script
hashes. No `unsafe-eval` or blanket inline-handler permission is added. Legacy
`onclick` attributes become declarative handlers; a bounded dispatcher supports
`copyLink`, `copyText`, `showQR`, `openQRModal`, `closeModal` and propagation control.
HTML-builder label/URI substitutions are escaped. Other event functions or library
APIs require an explicit adapter or a normal self-hosted script/event listener.
This is tested compatibility with these three examples, not a promise that every
third-party HTML template is supported unchanged.
